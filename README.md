## TP Restaurant

Projet front-end simple (HTML/CSS) présentant un site de restaurant avec une page d’accueil et une page recette.

### Contenu du dossier
- `index.html` : page d’accueil
- `recipe1.html` : exemple de page recette
- `screen.css` : feuille de styles principale
- `img/` : images utilisées sur le site
- `font/` : polices Source Sans Pro
- `snazzy-maps-example-ultra-light-with-labels-style.html` : exemple de style de carte

### Prérequis
Aucun outil obligatoire. Un simple navigateur web suffit (Chrome, Firefox, Safari…).

### Démarrage
1. Ouvrir le dossier du projet.
2. Double-cliquer sur `index.html` pour l’ouvrir dans le navigateur.

Option (recommandé pour le développement) : utiliser une extension Live Server dans votre éditeur (VS Code, Cursor) pour recharger automatiquement les changements.

### Personnalisation rapide
- Styles : modifier `screen.css`.
- Images : remplacer/ajouter des fichiers dans `img/` (garder les mêmes noms pour éviter de changer le HTML).
- Polices : fichiers dans `font/` (déjà intégrés via CSS).
- Contenu : éditer `index.html` et `recipe1.html` avec votre éditeur.

### Technologies
- HTML5
- CSS3 (mise en page, typographie, images)

### Notes
- Le projet est purement statique, sans JavaScript ni backend.
- Compatible avec les navigateurs modernes.
